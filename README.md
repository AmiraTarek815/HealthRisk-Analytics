# Multi-Disease Prediction System

A Machine Learning project that provides prediction systems for multiple diseases through a single interactive platform.

##  Overview

The project focuses on developing a separate Machine Learning prediction system for each selected disease, using its own dataset, preprocessing techniques, and trained model.

The final application will bring these systems together in an interactive website where users can select a disease, enter the required medical information, and receive a prediction.

The project will also include **data analysis, visualizations, model evaluation, dashboards, and deployment**.

##  Objectives

* Collect and prepare datasets for multiple diseases.
* Clean, preprocess, and analyze each dataset.
* Perform EDA and create meaningful visualizations.
* Train and compare different Machine Learning models.
* Select and evaluate the best-performing model for each disease.
* Develop an interactive dashboard and prediction interface.
* Deploy the complete application as a web-based platform.

##  Machine Learning

Different classification algorithms will be explored and compared, including:

* Logistic Regression
* KNN
* Decision Tree
* Random Forest
* SVM
* Gradient Boosting
* Neural Networks

Models will be evaluated using **Accuracy, Precision, Recall, F1-Score, and Confusion Matrix**.
